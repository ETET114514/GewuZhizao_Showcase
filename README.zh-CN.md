# 格物智造 · GewuZhizao

[English](README.md) | **中文**

**从二维户型图，到可编辑的三维室内场景。**

Browser-based floor plan recognition, editing and interior visualization.

格物智造是一个持续开发中的室内设计工具原型，将户型图片识别、人工校核、尺寸标定、空间编辑、材质与灯光整合到浏览器工作台中。识别得到的墙体、门窗和家具可以继续修改，并用于构建三维场景。

本仓库公开项目介绍、实际运行截图和技术架构概览。当前演示版本通过本地服务运行，尚未提供公开在线体验地址。

**项目状态：持续开发 · 展示更新：2026-10-28**

## 解决什么问题

二维户型图片中的墙体、洞口和家具信息，需要转为可编辑对象，才能进一步调整尺寸、布置家具和检查空间效果。项目围绕这条工作流展开：

**导入户型图 → 识别候选 → 人工校核 → 标定尺寸 → 二维编辑 → 三维设计 → 保存与出图**

识别结果作为编辑起点。用户可以修正误检、补充缺失对象、确认房间边界，再继续设计。
