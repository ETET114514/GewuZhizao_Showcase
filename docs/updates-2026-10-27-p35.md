| Area | Current behavior |
| --- | --- |
| Fixtures and finishes | Six refined procedural lamp types plus six project-original CC0 GLBs/thumbnails; local static product GLB import, orientation/size fitting and original-material restoration; four-part fixture PBR and independent ceiling, dropped-ceiling, cove and rail faces with physical texture origins. |

## Use and limits

Open **Detailing → Ceilings and lights → Ceilings, dropped ceilings and fixtures** (`做深化 → 顶面与灯光 → 顶面、吊顶与灯具`). Expand the curve/surface, variable-profile, rail-motion, section or brand-library controls as needed. Apply authored motion settings before previewing; stop resets to the applied position, while image export uses the currently visible frame.

Curves are adaptively sampled up to 4096 points. Surfaces are height fields suitable for ceiling slabs with vertical thickness; self-intersecting/folded shapes are rejected. Profile stations require matching vertex counts and a closed, valid seam. Section reconstruction has a 2.5-million-triangle budget; open imported meshes report unclosed contours instead of inventing a solid interior. Catalog JSON supports up to 2000 entries/16 MB, binds installed model IDs and SHA-256 hashes, rejects incorrect hashes atomically and reports missing model files explicitly. Model imports retain existing static-mesh/embedded-resource limits; rail transforms do not add skeletal animation support.

These are inspection/rendering tools. Professional illuminance/IES, power/circuit calculations, construction section drawings, video export and cloud rendering remain separate planned directions. Current collision uses the relevant surface triangles/envelopes.
