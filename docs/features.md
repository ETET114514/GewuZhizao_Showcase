# 功能与当前边界

更新日期：2026-10-23。以下按当前实现整理，区分已有功能与后续规划。

## 已有功能

| 模块 | 已有能力 | 当前边界 |
| --- | --- | --- |
| 图片导入 | PNG、JPG、WebP，底图与构件分层查看 | 当前不解析 DWG/DXF |
| 墙体识别 | 水平/垂直墙段候选，实心墙、双线墙及多墙色支持 | 特殊画法、短墙、斜墙与圆弧仍需补充和校核 |
| 门窗识别与编辑 | 候选确认/排除、沿墙新增/移动、洞口宽高与窗台调整 | 复杂符号可能误检或漏检；待定边界需确认 |
| 家具识别与补充 | 图例匹配与可选模型识别，手工补入或修改类别、范围、朝向 | 图例对样本来源敏感，未发布通用识别准确率 |
| 墙体校核 | 修改位置/厚度/长度、补墙、连接短缝、逐处闭合诊断 | 不保证自动修复整户；长距离缺墙仍需人工判断 |
| 精确画墙 | 空白画布或标定后临摹，连续水平/垂直墙、实际长度/墙厚、固定端、端点拖动、吸附与连接校核 | 首版不含斜墙、弧墙或局部墙高；边界变化后需校核房间装饰 |
| 比例与测量 | 两点已知长度标定；普通门洞/墙厚备选估算；墙轴线长与参考面积 | 估算依赖假定尺寸；参考面积不等于建筑面积或工程量 |
| 房间区域 | 自动候选、手绘、重画、切分、合并、排除与命名 | 漏墙、洞口或边界不完整会影响分区；未自动识别房间用途 |
| 三维墙体 | 墙段实体合并、相接墙角齐平、保留门窗上下墙体与真实洞口 | 以当前二维墙段和高度生成，尚非完整 BIM 构件系统 |
| 家具编辑 | 17 类程序化模型；尺寸、离地、朝向、自由旋转、移动、复制、吸附 | 厨房组操作见下项；通用家具分组和通道规范自动审查待做 |
| 真实模型 | 5 个内置 CC0 GLB；本地静态 GLB 导入、替换、单位/朝向校正、尺寸适配 | 首版限内嵌资源的静态网格，不含动画与压缩解码 |
| 材质 | 160 款基础材质，8 类各 20；另有 14 款家具专用材质与纯色色卡 | 支持墙面、地面、家具/门窗部位及顶面/吊顶/灯槽、墙板/格栅与踢脚线；用户贴图上传、任意网格部位编辑待做 |
| 地面起铺点与铺法 | 正铺、二分之一/三分之一错缝，单块尺寸、底图实际坐标起点、缝宽/缝色、方向；凹形/孔洞/多块区域真实切块，二维示意与三维同步，贴图覆盖比例独立 | 旧项目默认连续贴图，主动开启排版；排版块数非采购用量，不含单块自由编辑、真实人字拼/鱼骨、损耗与施工图 |
| 门窗开合 | 单扇平开、固定窗、双开门、子母门、双轨推拉；侧开/上下转动、批量开合 | 推拉首版为两轨两扇，一活动扇一固定扇，最大腾出约半个洞口 |
| 多扇组合窗 | 横向 2～6 扇，宽度占比、固定/左右平开/上下翻开、逐扇角度，材质与二维/三维同步 | 不含上下横梃、纱窗或逐扇独立材质 |
| 转角窗 | 同高、相接直角窗共用固定框，各扇独立开启 | 不同高度、非直角及存在歧义的连接不自动强接 |
| 顶面与吊顶 | 整房/局部/边吊/多级跌级、灯槽、安装面归属 | 已接入天花板/吊顶/灯槽真实材质；自由剖面、逐面赋材质与商品灯具待做 |
| 墙板与背景墙 | 平板/竖向格栅，墙段/墙侧、位置、尺寸、厚度、条宽/间隙与材质；平板规则网格分缝，两种样式均支持四周矩形收边及独立材质；避开实际门窗洞口 | 洞边包口/逐边例外、异形、嵌灯/电视柜组合、铺贴起点或自动柜体避让待做；失效宿主明确提示 |
| 单层矩形构件 | 柱、梁、烟道、包管；二维定位/拖动、尺寸/高度/离地，三维材质、阴影、复制、当前碰撞与行走 | 烟道/包管按占用外包体表达；不改变房间分区/面积、不自动开洞，多层与楼梯待做 |
| 定制衣柜与收纳柜 | 宽深高、板厚/背板/底座、1～6 个比例分格、层板/挂衣杆/内部抽屉、开放/单门/双门、逐格开合与部位材质 | 柜身按占地箱预留，当前打开门板/抽屉参与碰撞；厨房开孔另有结构/抽屉包络静态校验；完整内部机构/连续路径校核、清单或制造图纸待做 |
| 厨房水槽 / 灶具与开孔 | 普通地柜内矩形通孔，简化水槽/灶具；台面与柜顶板真实避孔，可改尺寸、局部位置和嵌入深度；直线/左右 L 形柜组移动旋转复制及保存恢复联动 | 最多每组 12 个；校验边距/孔距、隔板/层板/挂杆/抽屉包络，失配暂停显示。不含盲角柜/跨柜/异形孔、商品设备型号或水电燃气管线 |
| 厨房直线与 L 形组合 | 地柜/吊柜直排、左右盲位地柜 L 形排列，独立材质连续台面及厚度/外挑；L 形为单块凹多边形台面，凹口空置；数值/画布整组移动、0/90/180/270° 旋转与独立复制，保留结构/材质/开合 | 同系列/深度/柜高/离地；L 形限地柜，唯一盲角柜前后各至少一普通地柜。错位暂停台面，整组操作前需重排。最多 10 组、每组 1～12 柜、40 个活动定制柜；普通地柜矩形开孔已有，更多孔型、转角机构、U 形/多转角、L 形吊柜、任意角度和完整搬运路径待做 |
| 踢脚线 | 分房间开关、高度/厚度、纯色/PBR；依据实墙裁切并避开洞口 | 矩形截面；逐段例外、自定义线型和工程量待做 |
| 灯组与阴影 | 六类灯具，灯组开关/亮度/色温；日光与室内实时阴影 | 投影灯数受预算与显卡限制；不含 IES 与专业照度仿真 |
| 灯槽间接光 | 顶面照射及一次漫反射近似、附近墙面柔光、光路遮挡 | 显示顶面时启用；不含多次反射与离线全局光照 |
| 日光控制 | 方位、高度角、亮度、色温与阴影画质可调 | 方向按底图设置，尚不按地理位置和日期计算真实日照 |
| 碰撞与行走 | 当前姿态的碰撞框提示、第一人称受限行走 | 使用包围盒等近似；不做连续运动路径和施工规范判定 |
| 视角与图片 | 命名视角；JPG/PNG，最长边 1920/2560/3840，多种画幅 | 输出当前实时预览；不含全景、视频或可编辑模型导出 |
| 保存与撤销 | 预览取消、应用、最近 50 步撤销/重做、本机手动独立版本；已应用修改原子自动保存与恢复，含图片及导入 GLB | 未应用表单不恢复；跨次打开/恢复后撤销栈重新开始；无云同步与版本可视化比较 |
| 项目查找 | 当前方案命名、保存版本改名、缩略图及按名称/底图名/版本号搜索 | 最多展示 100 个匹配结果，仍为本机项目管理 |
| 操作流程 U01～U05 | 同一工作台顶部切换 2D/3D，共用五组工具与对象属性位置；可折叠三维小预览/二维相机定位图，家具/厨房移动轴、平面移动及旋转手柄；统一应用取消、Esc、未应用保护与无变化保护 | 手柄当前覆盖家具/厨房，厨房限直角；通用家具分组和完整搬运路径待做。辅助视图默认收起，二维缩放/滚动与三维镜头分别保留；复制/移除按对象既有范围显示 |
