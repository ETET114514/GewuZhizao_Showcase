# 2026-10-30 · Local CAD/template workflows and import tools

**English** | [中文](updates-2026-10-30.zh-CN.md)

Source checkpoint: [New d9338b5](https://github.com/ETET114514/GewuZhizaoNew/commit/d9338b5dd8194e8acb36768fa068e6626959531e). This release covers local changes since 01e2db7. The agreed local P21 version is accepted; the complete CAD roadmap remains open.

## Implemented

- **P21 structures and CAD**: seven editable structure templates, personal template metadata/JSON reuse, quarter-turns/mirroring, thumbnails and room names/net areas/bounds. Text/binary DXF supports explicit units/layers, ordinary planar blocks/arrays/nonuniform transforms, rotation proposals and cropping. Optional text/attached ATTRIB, saved dimension graphics, solid/pattern fills with holes, and basic dash/lineweight display remain reference graphics.
- **P21 confirmed modeling**: explicit centerlines or selected orthogonal parallel-boundary candidates create real walls. Boundary candidates expose inferred thickness, source layers and pairing conflicts; bounded corner joins do not bridge authored door gaps. Explicit symbol layers propose quarter-arc doors/closed rectangular windows with unique hosts and overlap checks. Users select openings and room-name candidates before independent creation. Dimensions, failures and stale inputs are validated again; cancel preserves the source.
- **P17 import compatibility**: separated-resource glTF ZIP and embedded .gltf normalize into existing static GLB workflows for furniture and lamps, carrying buffers/textures, part materials, unit/orientation and project portability. Bounded parsing rejects ambiguous paths, missing resources, unsupported compressed/animated input and invalid packages; it does not fetch external URLs.
- **P30 routes**: bounded obstacle-avoiding walking and fixed-pose furniture routes, followed by continuous checks against current modeled walls/openings/floor and height/clearance. Only a validated result replaces route inputs; the scene is not moved.
- **P31 tools**: stretch/rotation/shear/four-corner perspective image copies, bounded line-evidence proposals, local Chinese/English OCR, confirmed room names, complete rectangle/polygon annotations and grouped whole-image evaluation CLI. Copies require a new recognition/tracing/calibration workflow; existing project objects are not transformed.

## Evidence

Latest P21 records: **138 DXF Python checks, 41 template checks, 24 project/opening regressions, 19 display/label rechecks and 48 final targeted source checks** passed. Sets overlap and are not summed. **514 frontend tests** and **50 new / 165 existing P21 browser groups** passed, including actual downloads, desktop/390 px, conflict correction, cancel/stale rejection, undo/redo, real 3D, save/reopen and source isolation. New synthetic DXFs include a combined boundary-wall + fill + opening + room-name HTTP workflow.

Earlier local-round evidence is retained as historical: P17 38 targeted Python checks and 15 furniture / 6 lamp browser groups; P30 13 carrying and 11 walking groups; P31 a 583-test Python snapshot followed by 54 targeted checks and 29 workbench / 37 correction browser groups. These were not rerun as a full Python publication suite. Six fully annotated synthetic images verify evaluation plumbing, not independent real-world accuracy.

## Still outside the delivered scope

DWG; arbitrary angled/curved editable walls; clipped/dynamic/non-planar special blocks; precise CAD fonts/complex typography, constant ATTDEF, gradients/complex shape line types and uncached dimension reconstruction; arbitrary wall/opening/furniture semantics; independent real labeled CAD/image validation. Source line weights are raster-limited, and nonuniform dash spacing is approximate. Doors/windows are confirmed basic closed instances, not reconstructed product mechanisms or CAD leaf poses.

Automatic route turning/lifting/tilting, new-model addition and universal transport guarantees remain pending. Compression/animation model decoding, professional drawings/export, cloud/accounts and deferred P25 mechanisms are separate scope. Seven templates are structure skeletons, not complete or code-certified residential designs; there is no nationwide neighborhood library.
