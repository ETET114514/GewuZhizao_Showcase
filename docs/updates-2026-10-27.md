## 已有功能

| 范围 | 已接入能力 |
| --- | --- |
| P16 临时多选 | 家具、独立构件与灯具框选/点选，Shift 加选、Alt 减选；无需先建组即可直接移动、旋转、复制、删除。 |
| P16 混合与嵌套 | 混合组、嵌套组、名称/成员编辑、解除/删除；复制独立对象并重绑树内引用，保留宿主约束。 |
| P16 编辑与路径 | 等比占地缩放、可选高度同步，共同/同类批量属性，单件二维旋转、任意角度框内适配，多段平移/旋转及自定义通道净距检查。 |
| P18 五图 PBR | 颜色、法线、粗糙度、金属度、AO，OpenGL/DirectX 法线；无损数据图、整组校验及内容去重。 |
| P18 GLB 部位 | 源节点/网格/primitive 稳定选择，原 UV/实体尺寸投影，恢复模型原材质，模型内容指纹隔离替换。 |
| P18 房间墙侧 | 自动实际邻接，同一侧跨房间按局部区间裁切，保留洞口/墙角；单面覆盖、全墙覆盖与恢复规则明确。 |
| P18 批量材质 | 位置清单、类型/名称筛选及 P16 所选对象范围；赋材质、按源材质替换、保留各处参数、恢复。方案版本过期则拒绝应用。 |
| P18 库与缓存 | 上传库多选、前后缀改名、批量移除；查看缓存占用和保护原因，清理前重新核查当前方案、历史、保存版本、恢复及预览引用。 |
| 编辑与携带 | 预览/取消/Esc、一次应用一步历史、失败原子拒绝、无变化保留重做；五图/GLB 部位随保存、恢复及复制携带，旧颜色图兼容。 |

补查修复了批量赋材质误改地面排版方向/清除逐块记录的风险，保留格子身份和布局；单块纹理角度仍可独立修改。缓存文件被系统占用时保留隐藏状态和重试入口，清理拒绝链接与越界路径。

## 已设想、未实现与当前约束

P16 按用户确认的家具、独立构件和灯具范围完成；构件/厨房继续使用正交约束，灯具保持宿主安装面。路径检查基于当前碰撞包络及自定义水平净距/通道净高，不能推断商品内部空腔，不含搬运抬举、倾斜或机构变形，也不声明指定建筑规范合规。厨房任意角度和新增商品机构另定范围。

P18 按 M01～M08 完成。每张图最多 12 MB、1600 万像素，整组合计最多 48 MB，最长边规范为 2048；颜色图为不透明 JPEG，透明区域铺白，数据图为 PNG。颜色图必选，其余四通道可选；不生成贴图，不接入透明/位移/高度贴图、网格建模或骨骼动画。灯具商品模型与外观归 P35，云资产同步另列范围。

单批最多 500 个材质位置，单 GLB 最多 512 个可编辑部位，可分批操作。房间轮廓重叠时需先校核，归属歧义回退并提示；全墙、指定单面、房间墙侧分开操作以明确覆盖关系。缓存仅清理已移出库且无保留引用的资源，无法核查的记录阻止删除。库操作不修改方案及其历史。

P23、P16 与 P18 按确认范围收尾后，当前仍有 20 个后续方向：12 个已有主要流程，8 个所列目标流程未接入；不将该数字作为完成率。模型/CAD 导出、施工图、报价、云协作和生成式设计继续保留在[当前边界](features.md)。
