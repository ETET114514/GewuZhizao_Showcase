## Additions and fixes

- Initial precise orthogonal walls: blank/traced plans, continuous drawing, physical length/thickness, endpoint editing, snapping and connection/opening checks.
- Flat feature panels, vertical slats and room skirting with dimensions, position, materials and clipping to actual openings.
- Actual materials for ceilings/dropped ceilings/coves; horizontal multi-leaf windows with per-leaf operation.
- Local autosave/recovery, redo, project names/thumbnails/search and version renaming. Recovery carries plan images/imported models; manual saves remain independent versions.
- Publication rules in source README/FEATURES: New holds the complete project; each push also updates Showcase summaries, with both remote heads verified before reporting completion.
- Replaced fake images in two older save-API tests with real PNGs and matching image verification metadata.

## Still pending at this stage
