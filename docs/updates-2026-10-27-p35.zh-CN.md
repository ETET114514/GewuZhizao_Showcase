## 使用与边界

进入**做深化 → 顶面与灯光 → 顶面、吊顶与灯具**，按需展开自由曲面、沿程变截面、轨道运动、剖切或品牌库。先应用运动设置再播放；停止恢复已应用位置，出图使用当前可见帧。

曲线自适应离散，最多 4096 点。曲面为适合吊顶的高度曲面，厚度沿竖直方向；拒绝自交/翻折形状。变截面要求对应点数量一致、接缝闭合有效。剖切重建预算为 250 万三角面，开放导入网格报告未闭合截线，不猜测实体内部。目录 JSON 最多 2000 条/16 MB，绑定实际安装模型 ID 与 SHA-256；错误哈希整批拒绝，缺少模型文件明确报告。模型导入仍受静态网格/内嵌资源边界限制，轨道变换未增加骨骼动画支持。

这些是查看和渲染工具。专业照度/IES、供电/电路计算、施工剖面图、视频导出与云渲染仍由各自规划方向承接。当前碰撞使用对应曲面三角区域/包络。
