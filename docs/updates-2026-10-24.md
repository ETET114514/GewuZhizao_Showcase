## Planned and unimplemented at this stage

- P18: multi-map PBR, library rename/delete, further dedicated panels, arbitrary GLB mesh editing and more batch replacements. Opaque color only; input ≤12 MB/16 million pixels, longest edge 2048, transparency flattened to white.
- P23: chevron/complex motifs, free per-piece movement/scaling/actual geometry deletion, reveals/per-edge profile materials, irregular feature walls, procurement waste/construction drawings. Herringbone length exceeds width without requiring an integer ratio; candidate caps 6000/room and 24000/project, with 1000 per-piece overrides/room.
- P16: nested/mixed groups, box/multi-selection and full transport paths; up to 50 groups, each object in one general/kitchen group; arbitrary-angle kitchen groups pending.
- Surrounds are decorative strips on the wall face outside openings, without reducing clear dimensions; doors/full-height windows have no bottom strip. They are not opening-depth reveals at this stage.
- Drawing/model exchange remains lower priority. See [limitations](features.md); this round does not complete all planned P18/P23 scope.
